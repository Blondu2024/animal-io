# animal-io

## 📌 Start aici
Citește **[`animal-io-PROIECT-MASTER.md`](./animal-io-PROIECT-MASTER.md)** — documentul unic cu tot: context, concept, stack, faze, sesiuni, reguli de lucru.

2. Pornește `claude` din director.
3. Primul prompt: „Citește animal-io-PROIECT-MASTER.md, continuăm cu sesiunea 1a."
