**Pipeline (reutilizabil pe ORICE personaj biped, inclusiv animale antropomorfe viitoare):**
1. Model din **Meshy** (`.glb`)
2. **glb → FBX** prin **Unity FBX Exporter** (pachet `com.unity.formats.fbx`, instalat). Script: `Assets/Editor/ExportArcherFbx.cs`, menu `MCP/Export Archer FBX`. (Meshy NU exportă fbx pt text-to-3d, doar glb; Mixamo NU acceptă glb → de-asta conversia.)
3. User urcă FBX pe **Mixamo** (manual, ~10 min — Mixamo NU are MCP, eu nu pot da click). Auto-rig Humanoid + descarcă animații. Regula: 1× **With Skin** (Idle) = corpul, restul **Without Skin**. Setări: FBX for Unity, 30fps, no keyframe reduction.
4. Import FBX în Unity, set **Rig = Humanoid, CreateFromThisModel**. Script: `Assets/Editor/SetMixamoHumanoid.cs`, menu `MCP/Set Mixamo FBX to Humanoid`.
5. Animator + scenă: `Assets/Editor/BuildArcherMixamoTest.cs`, menu `MCP/Build Archer Mixamo Test`.
